# 修复手动上传按钮不显示问题

## 🐛 问题描述

Free 用户的视频处理完成后，状态变为 `205`（等待手动上传），但**看不到手动上传按钮**。

## 🔍 根本原因

**前端代码逻辑错误**：

```tsx
// ❌ 错误：只检查状态 200 和 299
const canUploadVideo = ['200', '299'].includes(status);
```

**状态流转**：
```
处理完成 → 状态 200
    ↓
调度器检查权限
    ↓
Free 用户：状态 205（等待手动上传）❌ 按钮不显示！
Pro 用户：状态 201（上传中）
```

## ✅ 修复方案

### 修改文件：`web/src/components/video/VideoActions.tsx`

**修改 1：扩展状态检查**

```tsx
// ✅ 修复后：添加状态 205
// 200: 准备就绪（可自动上传）
// 205: 等待手动上传（Free 用户或手动上传模式）
// 299: 上传失败（可重试）
const canUploadVideo = ['200', '205', '299'].includes(status);
```

**修改 2：更新提示文本**

```tsx
<p className="text-xs text-gray-500 mt-1">
  {status === '200' && '视频已准备就绪，可以立即上传'}
  {status === '205' && '等待手动上传，点击按钮立即上传'}
  {status === '299' && '视频上传失败，可以重试'}
</p>
```

## 📊 完整的状态码说明

### 视频处理状态

| 状态码 | 名称 | 说明 | 手动上传按钮 |
|--------|------|------|-------------|
| `001` | 待处理 | 刚提交，等待处理 | ❌ |
| `002` | 处理中 | 下载、字幕、翻译、元数据 | ❌ |
| `200` | 准备就绪 | 处理完成，可以上传 | ✅ |
| **`205`** | **等待手动上传** | **Free 用户或手动模式** | ✅ |

| `299` | 上传失败 | 上传失败，可重试 | ✅ |
| `300` | 视频已上传 | 等待上传字幕 | ❌ |
| `399` | 字幕失败 | 字幕上传失败，可重试 | ❌ |
| `400` | 完成 | 全部完成 | ❌ |

## 💡 额外说明

### 状态 205 的用途

状态 `205` 有两个用途：

1. **Free 用户**：自动上传被禁用，需要手动触发
2. **手动上传模式**：用户选择手动控制上传时机

### 为什么需要手动上传按钮

- Free 用户无法自动上传，但应该允许手动上传
- Pro 用户可以选择立即上传，不用等待调度队列
- 上传失败后可以快速重试
