# 会员系统动态化重构实施指南

## 📋 文档信息

- **创建日期**: 2026-01-09
- **版本**: v1.0
- **目标**: 将会员配置从硬编码改为 API 驱动，为迁移到 pay-unify 做准备
- **预计工期**: Phase 1 (1天), Phase 2 (1-2周)

---

## 🎯 方案概述

### 背景问题

**当前状态**:
```typescript
// web/src/components/membership/TierComparisonTable.tsx
const tiers = [
  { id: 'basic', name: '基础版', price: '¥29/月', dailyQuota: '10', ... },
  { id: 'pro', name: '专业版', price: '¥99/月', dailyQuota: '50', ... },
  { id: 'enterprise', name: '企业版', price: '¥299/月', dailyQuota: '无限', ... },
];
// ❌ 前端硬编码配置
```

**存在问题**:
1. ❌ 配置分散在前端代码中
2. ❌ 修改配置需要重新发版
3. ❌ 无法与 pay-unify 共享配置
4. ❌ 运营无法自助修改

### 目标架构

**Phase 1: 内部 API 化** (1天)
```
前端 ──GET /api/v1/license/plans──> ytb2bili 后端 (代码硬编码)
```

**Phase 2: 迁移到 pay-unify** (1-2周)
```
前端 ──GET /api/v1/license/plans──> ytb2bili 代理 ──> pay-unify (数据库驱动)
```

### 收益

| 维度 | 改进 |
|------|------|
| **前端** | 从硬编码改为 API 驱动，学会"听后端指挥" |
| **后端** | 统一数据出口，为迁移做准备 |
| **运维** | Phase 2 后，运营可通过后台修改配置 |
| **扩展** | 多系统可共享同一套会员配置 |

```go
// GetPlans 获取会员套餐列表
// @Summary 获取会员套餐列表
// @Description 返回所有可用的会员套餐配置（公开接口，无需认证）
// @Tags 会员管理
// @Accept json
// @Produce json
// @Success 200 {object} resp.Response{data=[]types.TierConfig}
// @Router /api/v1/license/plans [get]
func (h *LicenseHandler) GetPlans(c *gin.Context) {
    // 获取所有套餐配置
    plans := []types.TierConfig{
        types.GetTierConfig(types.TierBasic),
        types.GetTierConfig(types.TierPro),
        types.GetTierConfig(types.TierEnterprise),
    }

    resp.SUCCESS(c, plans)
}
```

**注册路由** (在 `RegisterRoutes` 函数中):

```go
func (h *LicenseHandler) RegisterRoutes(s *core.AppServer) {

    {

}
```

**新增 API 方法**:

```typescript
/**
 * 获取会员套餐列表
 * @returns Promise<TierConfig[]>
 */
async getPlans(): Promise<TierConfig[]> {
  const apiBaseUrl = getApiBaseUrl();
  const res = await fetch(`${apiBaseUrl}/api/v1/license/plans`);

  const data = await res.json();
  if (data.code === 0) {
    return data.data;
  }

  throw new Error(data.message || '获取套餐列表失败');
}
```

```go
import (
```

```go
func (h *LicenseHandler) GetPlans(c *gin.Context) {
    // 调用 pay-unify API
    resp, err := http.Get("http://localhost:8097/api/v2/tiers")
    if err != nil {
        resp.ERROR(c, "获取套餐失败", err.Error())
        return
    }
    defer resp.Body.Close()

    var payUnifyResp struct {
        Code int    `json:"code"`
        Data []struct {
            Tier               string `json:"tier"`
            Name               string `json:"name"`
            Price              string `json:"price"`
            DailyUploadLimit   int    `json:"daily_upload_limit"`
            MaxConcurrentTasks int    `json:"max_concurrent_tasks"`
            MaxVideoDuration   int    `json:"max_video_duration"`
            StorageLimit       int64  `json:"storage_limit"`
            Features           string `json:"features"`
        } `json:"data"`
    }

    if err := json.NewDecoder(resp.Body).Decode(&payUnifyResp); err != nil {
        resp.ERROR(c, "解析响应失败", err.Error())
        return
    }

    // 转换为前端需要的格式
    plans := make([]types.TierConfig, len(payUnifyResp.Data))
    for i, tier := range payUnifyResp.Data {
        plans[i] = types.TierConfig{
            Tier:  types.Tier(tier.Tier),
            Name:  tier.Name,
            Price: tier.Price,
            Features: types.TierFeatures{
                // 解析 JSON 字符串
            },
            Limits: types.TierLimits{
                DailyUploadLimit:   tier.DailyUploadLimit,
                MaxConcurrentTasks: tier.MaxConcurrentTasks,
                MaxVideoDuration:   tier.MaxVideoDuration,
                StorageLimit:       tier.StorageLimit,
            },
        }
    }

    resp.SUCCESS(c, plans)
}
```

```go
// 新增反向代理中间件
func ProxyMiddleware(targetURL string) gin.HandlerFunc {
    return func(c *gin.Context) {
        target := targetURL + c.Request.URL.Path
        proxy := httputil.NewSingleHostReverseProxy(
            &url.URL{
                Scheme: "http",
                Host:   strings.TrimPrefix(targetURL, "http://"),
            },
        )

        // 修改请求
        director := func(req *http.Request) {
            req.URL.Scheme = "http"
            req.URL.Host = strings.TrimPrefix(targetURL, "http://")
            req.Host = req.URL.Host
        }

        proxy.Director = director
        proxy.ServeHTTP(c.Writer, c.Request)
    }
}

// 在路由注册中使用
func (s *AppServer) SetupRoutes() {
    // ... 其他路由

    // 反向代理到 pay-unify
    s.Engine.GET("/api/v1/license/plans", ProxyMiddleware("http://localhost:8097/api/v2/tiers"))
}
```

### Q1: 前端显示"加载中"但不显示数据？

```bash

# - Console 标签查看错误信息

# 3. 检查跨域问题
# 如果 CORS 错误，检查后端 CORS 配置
```

### Q2: 价格显示为 undefined？

**原因**: 后端返回的数据缺少 `price` 字段

**排查**:
```bash
# 1. 检查 API 响应
curl http://localhost:8096/api/v1/license/plans | jq '.data[0].price'

# 2. 如果为 null，检查 GetTierConfig 是否正确赋值
```

### Q3: Phase 2 后数据不一致？

**原因**: pay-unify 和 ytb2bili 配置不同步

**解决**:
```sql
-- 检查 pay-unify 数据库
SELECT * FROM cw_tier_configs;

-- 手动同步配置
UPDATE cw_tier_configs SET
  daily_upload_limit = 10,
  max_video_duration = 60
WHERE tier = 'basic';
```
