## 🔧 技术实现

### 架构设计

```
┌─────────────────────────────────────────────────────────┐
│                   应用层 (Application)                   │
├─────────────────────────────────────────────────────────┤
│  main.go                                                │
│  ├─ fx.Invoke(InitProgressLogManager)                  │
│  └─ 全局单例进度管理器                                   │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│                  智能日志层 (Smart Logger)                │
├─────────────────────────────────────────────────────────┤
│  SmartLogger                                            │
│  ├─ 自动检测进度活动                                     │
│  ├─ 过滤噪音日志                                         │
│  └─ 保留重要信息                                         │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│               进度管理层 (Progress Manager)               │
├─────────────────────────────────────────────────────────┤
│  ProgressLogManager                                     │
│  ├─ atomic.Int32 活动计数                               │
│  ├─ 日志过滤规则                                         │
│  └─ ANSI 转义码支持                                      │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│              进度显示层 (Progress Display)                │
├─────────────────────────────────────────────────────────┤
│  CompactProgressLogger                                  │
│  ├─ 单行覆盖更新 (\r)                                    │
│  ├─ 多种格式支持 (aria2c, yt-dlp)                        │
│  └─ 自动清理进度行                                       │
└─────────────────────────────────────────────────────────┘
```

### 关键技术点

1. **线程安全**: 使用 `atomic.Int32` 管理活动计数，无锁竞争
2. **智能过滤**: 自动识别并过滤噪音日志
3. **ANSI 转义**: 使用 `\r` 实现单行覆盖，无滚动
4. **渐进集成**: 可与现有代码并存，分阶段迁移
5. **零性能开销**: <1μs 的过滤判断，4 bytes 内存
